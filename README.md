# Azure VM Hardening Lab

## Project Overview

This project demonstrates how to deploy and secure a Microsoft Azure Windows Virtual Machine following Microsoft security best practices.

---

## Objectives

- Deploy a Windows Virtual Machine
- Configure Network Security Groups (NSGs)
- Restrict Remote Desktop (RDP) access
- Enable Microsoft Defender for Cloud
- Configure automatic Windows Updates
- Enable Azure Backup
- Apply Role-Based Access Control (RBAC)

---

## Technologies Used

- Microsoft Azure
- Azure Virtual Machines
- Azure Network Security Groups
- Microsoft Defender for Cloud
- Azure Backup
- Azure RBAC

---

## Security Improvements

- Restricted inbound RDP traffic
- Enabled Windows Firewall
- Installed Windows Updates
- Enabled Microsoft Defender recommendations
- Configured Azure Backup
- Applied least-privilege permissions
